# Succend Web

Succend is a gamified goal-achievement platform designed to help users
set goals, track progress, complete goals, earn XP, level up, and
progress through a personalized character and reward system.

## Version 0.1

The first MVP will focus on:

- Account creation and login
- Goal creation and goal-setting
- Goal progress logging
- Goal completion and submission
- XP and leveling
- Basic achievements
- Character customization
- MVP shop
- Settings
- Post-goal continuation decisions

## Development

This repository contains the web application for Succend Version 0.1.

The project will be developed in stages:

1. Frontend
2. Backend
3. Database
4. Integration and testing
5. Deployment
